2026-06-02 · Life & learning

We can learn about the world through tools in two broad ways: by understanding before use, or by understanding through use.

The first says: “Learn the tool, then use it.”

The second says: “Use the tool, then let experience teach you what matters.”

Some tools you learn before you use. Others you use to learn.
