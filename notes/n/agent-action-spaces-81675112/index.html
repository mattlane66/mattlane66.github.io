Agent Action Spaces

In the coming years, we may move away from the human-computer interaction model and toward an “agent-action space” model.

We’ll need to start thinking about how action-space design patterns work best for “agentic intent” rather than human actors alone. It’ll be generative plus parametric.

Agent Affordances: Interfaces must convey what agents can do in context, akin to showing affordances for physical objects. People will need clarity on the agent’s toolset.

This vision suggests a radical shift where interaction is less about doing and more about guiding intent, delegating to intelligent agents, and refining results. Designing for such systems will require new mental models, interaction paradigms, and an embrace of co-creative dynamics.
