2025-06-08 · AI & future work

Get stable, repeatable AI answers

Turn off randomness:

- Use temperature = 0 and always use the same seed (like 12345).
Force a reply structure:

- Tell the AI exactly what format to use, e.g., “Answer as a JSON with ‘summary’ and ‘tags’ only.”
Set a stopping point:

- Add “END” at the end of your question and ask the AI to stop when it gets there.
Limit answer choices:

- Tell the AI: “Only answer Yes or No” (or any other specific set of words).
Use the AI to improve your own prompt (meta-prompting):

  • Ask: “Rewrite *this* prompt, reasoning step-by-step in a clear, complete, reliable, and structured way.” Use that version instead.
