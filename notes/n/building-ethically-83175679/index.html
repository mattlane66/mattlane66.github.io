Building Ethically

Just a few “should we do this?” questions software companies often don’t ask in the following ways regarding their designs:

  • Empowerment: Who’s having the fun (should the technology grow — or the person using it)?
  • Resilience: Does it make us more vulnerable (and more complicated because the system is more complicated)?
  • Empathy: What is the impact of simplification on others (we need to know things more transparently if we want to be better)?
