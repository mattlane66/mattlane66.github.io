There’s nothing scientific about collecting data and trying to make inductive generalizations from it.

There’s nothing scientific about collecting data and trying to make inductive generalizations from it. That gets us nowhere. You need to inquire about the world. Craft the questions worth uttering you expect will surface valuable data and insights from running experiments. Synthesize learnings into new knowledge about the phenomena observed in the world.
