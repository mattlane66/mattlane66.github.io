Don’t Atrophy Via AI

Keep a manual spine. Automate limbs, not judgment.

Own the call. Delegation isn’t abdication.

Earn the question. State it, constrain it, name what changes your mind.

Do the first 15%. Frame, bound, estimate, sketch the system…then prompt.

Match tool to risk. Brainstorming can hallucinate; decisions can’t. Testable beats believable.

Never trust smoothness. Coherence ≠ correctness.

Triangulate + touch primary. One source is a story; originals keep you honest.

Preserve the struggle. Offloading difficulty offloads learning—choose your easy.

Do the last 15%. Verify, test when it matters, check counterfactuals, log bets.

Protect the boundary + stay trainable. No sensitive data in unapproved tools; calibrate to avoid quiet atrophy.
