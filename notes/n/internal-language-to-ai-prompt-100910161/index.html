Internal Language to AI Prompt

**1. Crafting Deterministic, Precise Prompts:**

To instruct AI deterministically, follow these principles:

• Explicit Clarity:

Specify exactly what to do, how to do it, and clearly define expected outcomes.

Example:

Instead of:

```
“Summarize this article”
```

Say:

```
“Summarize this article in exactly 100 words, focusing specifically on key facts and omitting opinions or speculation.”
```

• Structured Format:

Break instructions into clearly labeled subsections or enumerated steps.

Example:

```
1. Read the provided text.
```

```
2. Extract key points regarding X and Y.
```

```
3. Present a numbered list of extracted points.
```

```
4. Do not include commentary or interpretations.
```

• Limit Ambiguity:

Explicitly rule out unwanted behaviors.

Example:

```
“Do NOT include any interpretations, personal opinions, or additional suggestions beyond precisely summarizing the given text.”
```

• Context Specification:

Clarify context explicitly if relevant to avoid misinterpretation.

Example:

```
“Assuming the audience is software engineers proficient in Python but unfamiliar with the TensorFlow library, provide instructions to install TensorFlow clearly step-by-step.”
```

• Use Constraints:

Explicitly add constraints (length, style, tone, specifics).

Example:

```
“Answer this question precisely in one short paragraph of maximum 5 sentences, using plain English and no jargon.”
```

**2. Converting Internal Understanding into Deterministic Instructions:**

• Formalization: The translation of internal or intuitive knowledge into explicit, logically rigorous, and unambiguous terms.

• Disambiguation: Eliminating ambiguities inherent to human thought and language, ensuring each word or phrase maps directly and consistently to exactly one meaning or action.

To do this effectively:

• Formal Specification: Use formal logic or pseudocode to precisely describe instructions, especially beneficial for programming, automation, and AI interactions.

Example (Pseudocode):

```
For each sentence in document:
```

```
If sentence contains fact (dates, names, figures):
```

```
Add sentence to summary_list
```

```
Else:
```

```
Skip sentence
```

```
Return summary_list ordered chronologically
```

• Controlled Natural Language (CNL): A simplified and restricted subset of natural language designed explicitly to remove ambiguity. CNL aims for deterministic interpretation by machines.

• Operationalization: Clearly describe not what you internally think, but explicitly how to perform or identify a task step-by-step.

• Iterative Refinement: Constantly revise your prompts based on the results you receive to further remove ambiguity, clarify intentions, and move towards determinism.
