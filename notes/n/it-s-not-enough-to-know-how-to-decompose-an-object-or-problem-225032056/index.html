2026-03-09 · Judgment & knowledge

It’s not enough to know how to decompose an object or problem.

To recompose with imagination, you also need to know how to ask of each part:

Does the system fail without this? If yes, it’s an epicenter.

Does this part have the most "unknowns"? If yes, it should be sequenced first.

Could this part work in a different product? If yes, it has transformational or adjacent possible potential.
