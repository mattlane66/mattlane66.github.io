When describing a dream to a generative image tool:

Describe only what you actually remember.

Prefer concrete particulars to interpretive labels.

Preserve what is strange, even if it feels impossible.

Do not invent what memory leaves blank.

Let arrangement, scale, light, posture, and action carry the feeling.

Keep uncertainty where memory is uncertain.

Add nothing merely to make the image richer.

Stop when added detail begins to replace the dream.
